# Personal Portfolio & Web Development Exercises

This repository contains the integrated code for my personal portfolio and various web development exercises, focusing on HTML, CSS, and responsive design techniques.

## Features Included

*   **Responsive Typography:** Dynamic font sizing using CSS variables for readability across devices.
*   **Adaptive Card Layout:** Flexible card components that switch from horizontal to vertical layouts based on screen size using Flexbox.
*   **Smart Navigation Bar:** A fully responsive navigation menu that transitions to a hamburger icon on mobile devices.
*   **Dark/Light Mode Theme:** An interactive theme toggler utilizing CSS variables for seamless switching between themes.
*   **Responsive Image Gallery:** A dynamic image grid that automatically adjusts the number of columns using CSS Grid.
*   **Mobile-First Contact Form:** A user-friendly contact form optimized for touch interactions and smaller screens.
*   **Personal Portfolio:** Integration of bio, projects, and skills into a unified single-page layout.

## Setup & Usage

To view the project:
1. Clone this repository.
2. Open the `index.html` file in your preferred web browser.

## Technologies Used

*   HTML5
*   CSS3 (Flexbox, Grid, Custom Properties/Variables)

## Development Process

The code has been consolidated into a single `index.html` file for simplicity and ease of review. The `ai_prompts.md` file contains the instructions and prompts used to assist in the development of this project.

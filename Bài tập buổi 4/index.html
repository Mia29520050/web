Design System Refactoring: Trích xuất biến CSS & Debug

Chuyển đổi toàn bộ các mã màu và khoảng cách "cứng" (hard-coded) thành biến CSS tại :root:

Trích xuất mã màu: Thay thế các mã màu #2563eb, #111827, #f5f7fb bằng var(--color-primary), var(--color-header-bg), var(--color-bg).
Trích xuất khoảng cách: Chuẩn hóa các giá trị padding, margin thành token --space-1 (8px), --space-2 (16px), --space-3 (24px), --space-4 (32px), --space-5 (40px).
Tối ưu hóa mã nguồn: Sử dụng Shorthand Properties (margin, padding), loại bỏ thuộc tính CSS trùng lặp hoặc dư thừa.
Kiểm thử Responsive: Mở DevTools (F12) > Toggle Device Toolbar (Ctrl + Shift + M) để kiểm tra layout ở kích thước <768px (Mobile) và 768px–1024px (Tablet). 
:root {
    /* Color Tokens */
    --color-primary: #2563eb;
    --color-secondary: #4f46e5;
    --color-gray-dark: #1f2937;
    --color-gray-medium: #6b7280;
    --color-gray-light: #e5e7eb;
    --color-bg: #f5f7fb;

    /* Spacing Tokens */
    --spacing-unit: 8px;
    --space-1: var(--spacing-unit);           /* 8px */
    --space-2: calc(var(--spacing-unit) * 2); /* 16px */
    --space-3: calc(var(--spacing-unit) * 3); /* 24px */
    --space-4: calc(var(--spacing-unit) * 4); /* 32px */
}

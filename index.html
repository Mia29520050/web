FLEX & GRID BATTLE

Thực hành căn chỉnh và bố cục bằng CSS

1. Flexbox — Căn giữa

Căn một hộp vào chính giữa theo cả chiều ngang và chiều dọc.

Nội dung ở chính giữa

Flexbox đang căn giữa phần tử này.

.container {
    height: 100vh;
    display: flex;
    justify-content: center;
    align-items: center;
}

2. CSS Grid — 3 cột

Tạo 3 cột bằng nhau với khoảng cách 20px.

Cột 1

width: 1fr

Cột 2

width: 1fr

Cột 3

width: 1fr

.grid-container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

.column {
    background: #e5e7eb;
    border-radius: 10px;
}
